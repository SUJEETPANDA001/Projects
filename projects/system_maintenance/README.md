# System Maintenance Suite (Bash Project)

## Objective
Automate Linux system maintenance tasks — backup, updates, and log monitoring — through a centralized suite.

## Scripts
1. `backup.sh` - Creates compressed backups of `/home`.
2. `update_and_cleanup.sh` - Updates and cleans the system.
3. `log_monitor.sh` - Scans system logs for errors.
4. `maintenance_suite.sh` - Centralized menu-driven interface.

## Features
- Automated backups with timestamps.
- System updates and cleanup automation.
- Log monitoring for critical issues.
- Centralized interactive suite.
- Error handling and logging support.

## Usage
```bash
chmod +x *.sh
sudo ./maintenance_suite.sh
```
